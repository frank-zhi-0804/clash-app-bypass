# Clash App Bypass · 直连助手

**中文** | [English](README.en.md)

面向 Windows 用户的 Clash Verge Rev 应用直连助手。选择不使用代理的软件，识别其关联进程，按完整程序路径生成直连规则。独立第三方项目，与 Clash Verge Rev 官方没有隶属关系。当前源码版本：**0.1.7**；界面目前为中文。

## 功能

- 无畏契约的 WeGame 启动器会关联同一安装目录中的游戏主程序、登录器和已知网络辅助程序，补齐跨目录的直连规则。
- 扫描开始菜单、桌面快捷方式和可读取路径的运行进程，也可手动添加 `.exe`。
- 搜索、运行中筛选、已选择筛选，展开查看关联进程。
- 根据产品信息和少量已知辅助程序名称关联同目录下的程序。
- 软件选择保存在本机；应用前重新扫描并检查程序路径。
- 使用 `PROCESS-PATH,...,DIRECT`，避免将其他同名程序一起直连。
- 管理全局扩展脚本中的专属区段，提供备份、冲突检测和撤销。
- 支持明暗主题；应用图标由项目根目录的 `app-icon.png` 生成。

## 使用

1. 打开桌面版，助手自动使用上次保存的 Clash 配置目录；留空时自动检测。连接检测与软件扫描分别显示结果，暂时读取失败会自动重试。首次使用未找到目录时，在设置中选择包含 `profiles.yaml` 的 Clash Verge Rev 配置目录。
2. 为需要直连的软件打开“不使用代理”，展开关联清单检查识别结果。
3. 设置“其他流量”：默认“使用代理”，代理组为 `GLOBAL`。确保它最终选择可用代理节点，而不是 `DIRECT`。
4. 选择后自动保存并同步规则；Clash 运行时会在线应用并验证，无需手动退出和重新启动。助手打开期间约每 30 秒刷新关联进程和规则状态。
5. 查看状态提示及新连接是否使用 `DIRECT`。需要接管不遵循系统代理的应用时，可在 Clash 中启用 TUN。
6. 已有默认代理规则切换到“遵循订阅规则”或撤销时，按提示退出 Clash 后操作，以恢复原订阅配置。

默认规则顺序为“所选程序路径 → DIRECT，其余流量 → MATCH,所选代理组”。这会覆盖运行配置中的订阅分流规则，但保留订阅原文和原脚本。“遵循订阅规则”则保留订阅分流行为，不保证特定网站走代理。

取消某个软件的选择后自动同步，会移除其直连规则。清空选择时，“使用代理”仍保留默认代理规则；点击“撤销本工具规则”可移除本工具管理段并保留软件选择，同时暂停自动应用。重新启用可点击“立即应用”或主动修改分流选择；后台扫描发现辅助进程不会自行恢复规则。

## 适用范围和限制

- 当前仅支持 Windows。浏览器预览使用示例数据，不扫描真实软件、不修改 Clash。
- 不保证识别全部相关进程。目录外共享服务、特殊启动器、无法读取路径的进程需要单独添加。
- 关联扫描最大深度为 3，最多访问 2000 个目录项，不跟随 junction / symlink；不会将同目录所有 `.exe` 一律直连。
- 主程序路径变化后需重新添加；失效辅助程序路径在刷新或应用前清理，仍存在的历史辅助程序路径保留。
- 默认适配具有 `uid: Script` 的全局脚本结构；不支持的入口形式或指向配置目录外的脚本会停止操作。
- 订阅级扩展可能覆盖全局规则或进程识别设置，请检查最终配置和实际连接。
- 在线应用成功会核对内核规则，但没有新连接时仍无法证明软件实际路线。已有连接可能保留旧路线；关闭助手后规则保留，关联进程自动刷新随之停止。

## 本机数据、备份与撤销

Tauri 的 `app_data_dir`（应用标识 `io.clashappbypass.app`）存放 `settings.json`、`ownership.json` 和 `backups/`。这些数据包含程序路径和原扩展脚本，本工具不会上传，请勿提交到公开仓库。

首次改写前备份原脚本，每次写入前检查 Clash 进程和源文件内容。管理区段被外部修改或缺少本机归属记录时，会停止修改。升级沿用同一应用数据目录和管理标记。

无法正常撤销时，退出 Clash，在本机数据目录查找修改前备份，通过 Clash 的全局扩展脚本编辑器检查并恢复。其他规则已变化时，请勿盲目覆盖整份旧脚本。

## 开发与构建

需要 Node.js 22 或更高版本；桌面版还需要 Rust stable（MSVC）、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。详见 [Tauri 环境要求](https://v2.tauri.app/start/prerequisites/)。

```powershell
npm install
node scripts/generate-icon.mjs
npm run dev           # 浏览器预览
npm run desktop       # 桌面开发
npm run desktop:build # Windows 安装包
```

也可双击 `start-web-preview.cmd`、`start-desktop.cmd` 或 `build-windows.cmd`，启动脚本会安装缺失的前端依赖并生成图标。直接执行桌面构建前，请先生成图标。安装包输出到 `src-tauri/target/release/bundle/nsis/`，便携程序为 `src-tauri/target/release/clash-app-bypass.exe`。

### 图标

`app-icon.png` 是原始图标。`node scripts/generate-icon.mjs` 使用本地 Tauri CLI 生成 `src-tauri/icons/` 中的桌面图标，并将 128 像素版本复制到 `public/app-icon.png`，供侧栏和浏览器标签使用。替换原图后重新运行该命令即可。

## 关联识别与实际连接检查（0.1.4）

启动和重新扫描会刷新已选软件的关联程序。除已知辅助程序外，工具会根据当前进程启动链显示候选程序；确认关联后，再重新应用规则。不会自动将启动器打开的所有软件设为直连。

打开所选软件并产生新连接后，点击“检查实际连接”。工具仅读取当前配置目录中本机命名管道的 Clash API，不修改模式、接口、规则或权限；不支持仅配置 TCP 接口的诊断。结果区分规则缺失、非规则模式、仍走代理、连接被拒绝、已观察到直连以及暂无连接。无法识别路径的连接会单独提示。快照包含旧连接，不能保证所有进程均已识别；启动器已退出、受保护进程或未知安装结构仍可能需要手动添加。

## 自动处理（0.1.5）

打开“不使用代理”开关后，助手会自动保存并尝试在线应用，在线成功后无需退出 Clash，并启用规则模式。助手打开期间约每 30 秒（上一轮完成后）刷新所选程序、补齐已知辅助程序并检查连接和已加载规则；关闭后停止检测，不安装常驻服务，已持久化规则继续有效。启动链中产品信息相同且有效签名证书相同的程序可自动关联，其他候选仍需确认。

在线应用仅使用现有本机命名管道接口，不增加权限或开启接口。先核验旧规则和网络设置，再备份并更新全局脚本及运行配置，重载后验证规则；失败时尝试恢复。检测到外部修改时保留现场，停止自动重试并提示处理。Clash 未运行时会保存规则，下次启动生效。旧版代理兜底规则缺少原订阅规则依据时，切回订阅分流或完整撤销需要一次性退出 Clash 后操作。

连接诊断是当前快照，不强制断开既有连接，不能保证所有未知或受保护进程都被识别。正常状态不会反复弹窗；需要时可立即检查或手动重试。

## 进一步测试与修复（0.1.6）

- 所选程序采用批量扫描，共享本轮进程、签名与目录缓存，减少重复扫描；缓存不会跨轮保留。
- 自动同步与手动操作互斥，避免新选择被旧状态覆盖；撤销后的暂停状态在刷新与升级时继续保留。
- 待生效状态依据实际加载的规则核对；写入成功后的连接检查失败会单独提示，规则被禁用或进程识别关闭不会被当作已生效。
- 在线失败恢复核对原路由模式、进程识别及可验证网络设置。订阅自带、恰好与工具规则相同的规则会保留，撤销只去掉工具新增部分。

测试覆盖自动同步、撤销、状态检查、关联信任边界及命名管道冲突和回滚；本机隔离内核验证在线应用、移除、重启持久性，以及规则相同时的模式恢复。外部配置的所有变化不能完全通过当前 API 核对；特殊或受保护的进程仍可能需要单独添加。

## 自动重连（0.1.7）

- 重新打开助手沿用已保存目录，连接结果无需等待完整软件扫描；启动检测期间显示“正在自动连接”。设置页显示实际检测到的目录，留空仍表示自动检测。
- 软件刷新、目录检测或接口读取暂时失败时自动退避重试，恢复后清除临时提示；不再因一次读取失败永久暂停自动检查。
- 写入或保存失败仍暂停自动写入，只读检查继续；重新连接不会自行恢复用户撤销的规则。
- Windows 共享目录显示保留绝对路径，避免保存后下次启动无法识别。
